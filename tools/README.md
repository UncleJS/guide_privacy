## What the website is

- Plain HTML, CSS, and one small JavaScript file. No server software, database, or build step on the host.
- Every link is relative, so it works from any sub-folder, such as `https://example.com/privacy/`, and even when opened straight from disk.
- Dark by default, with a light-mode toggle that is remembered on the visitor's device. Checklists are saved the same way and never leave the browser.
- No external fonts, scripts, or trackers.

## Publish it

1. Upload the **contents** of `web/` (including the `assets/` folder) to the folder you want on your web host, for example `public_html/privacy/`.
2. Open `https://your-domain/privacy/` (or `.../privacy/index.html`).

Nothing else is required. If your host does not serve `index.html` automatically, link to `index.html` directly.

## Rebuild it

Run this after changing any Markdown file. It uses a container, so nothing is installed on your computer:

```bash
podman run --rm -v "$PWD":/work:Z -w /work docker.io/library/python:3.12-slim \
  sh -c 'pip install --no-cache-dir -q -r tools/requirements.txt && python tools/build_web.py'
```

The script reads `README.md`, `LICENSE.md`, and `guide/*.md`, and rewrites the HTML files in `web/`. It does not touch `web/assets/`, which holds the hand-written `style.css` and `site.js`.

## Preview it locally

To check how it behaves in a sub-folder, serve it from a nested path in a container:

```bash
podman run --rm -d --name privacy-preview -p 8089:8000 \
  -v "$PWD/web":/srv/some/sub/folder:ro,Z -w /srv \
  docker.io/library/python:3.12-slim python -m http.server 8000
```

Then open `http://localhost:8089/some/sub/folder/`. Stop it with `podman stop privacy-preview`.
